Choosing a representation

Keep runs compressed
Integrals and bucket rollups are exact at any granularity. Cost scales with runs, so long constant stretches are nearly free. Best default; the residue bookkeeping costs one extra segment per re-cut.
Expand to fixed granularity
Needed only when a downstream tool demands dense rows. Cost scales with window width, which is fine for a 2-hour look and painful for a month. Store the expansion as a derived cache, never as the source of truth.
Revoked revisions
Replay skips revoked entries; the prior residues reappear exactly, with no compensating negative rows. A revoked revision still occupies a ledger position, so audit stays linear.
